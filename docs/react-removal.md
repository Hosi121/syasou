# React 依存の置き換え

画面の記述だけでなく、React / ReactDOM / Motion / Radix / Lucide React の実行時依存を外しました。MoonBit の `view` パッケージが状態・副作用・DOM 更新・spring を担当し、DOM、標準 `dialog`、Web Animations はブラウザ API を直接呼び出します。Lucide の図形データは ISC ライセンス付きで保持しています。

`view` はこのゲームに必要な機能に絞った実装です。React や Radix の公開 API 全体を再実装したライブラリではありません。入力欄・canvas・ポインター取得を保つため DOM を再利用し、イベント購読は安定した関数から最新の状態を参照します。切符の切り替えでは退出を待って次の紙を表示します。

タッチ操作では、旧 Radix のスクロール抑制が担当していた横スワイプのキャンセルを MoonBit へ移しました。これがないと、速いドラッグの直後にブラウザが次のタップを消費する場合がありました。横方向の切符操作だけを抑制し、縦スクロール・複数指のピンチは許可します。

## 検証

- MoonBit JS: 1,053 件成功。うち `view` の状態・副作用・参照・例外回復は 7 件。
- MoonBit native: 純粋なドメインの 1,045 件成功。
- 既存契約: reducer 207、保存検証 435、操作・旧保存変換 437、ブラウザ API トレース 15、UI 表示 21、表示ヘルパー 30 件成功。
- 変更していない Playwright シナリオ: デスクトップ 42、Android 相当 8 件成功。
- Vite 本番ビルドと preview で、案内・フォーカス・切符操作・入力の 4 件、および本体ダウンロード失敗からの再試行を確認。
- WebKit はこの実行環境に `libxslt.so.1` などの共有ライブラリがなく起動できず、今回再検証していません。

通常の CI は引き続き単体テスト・互換性・型・生成物の再現性・ビルドのみです。ブラウザ検証はローカルまたは手動実行です。

UI の比較元は旧 TSX から採取済みの HTML です。期待値を変更せず、React 固有の SSR 差分を限定して正規化しています。詳細は [移行契約](../tests/contract/README.md) にあります。旧 React の依存は、この期待値を再採取するときだけ `tests/contract/oracle/ui/` へ別途インストールします。通常のアプリ依存・CI・本番配信には含まれません。

## 配信サイズ

Node.js 24.13.0、各版の lockfile、Vite 8.3.0 でビルドし、`dist/assets/*.js` をファイルごとに Node の `gzipSync` で圧縮して合計しました。

| 比較対象 | JS gzip 合計 |
| --- | ---: |
| React 使用版 `91e51d1` の再ビルド | 217,966 bytes |
| 今回の DOM 直接描画版 | 59,699 bytes |

約 73% 減です。初期画面だけでなく、遅延読み込みする本体も含んだ値です。CSS・画像・フォントは含みません。

TypeScript は Vite の入口・既存公開 API の型と委譲・設定・テストに残ります。MoonBit の生成 JavaScript、ブラウザ境界の小さな JS FFI、CSS と GLSL も引き続き必要です。Vercel はコミット済み生成物を通常の Node/Vite でビルドするため、MoonBit のインストールは不要です。
