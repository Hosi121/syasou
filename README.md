# 車窓

PCやスマートフォンの画面を、モノクロの列車の窓辺にする作業用アプリ。窓と手帳そのものを操作します。

公開URL: https://syasou.vercel.app

公開リポジトリ: https://github.com/Hosi121/syasou

テスト用URL: https://syasou.vercel.app/?demo=1

現時点ではログインを使わず、ブラウザ内に保存します。テスト用URLでは別の保存領域を使い、読書・企画・メモのサンプル切符を3枚用意します。通常の手帳の作業・メモ・設定・切符は変更しません。サンプルは初回だけ用意し、編集や新しい切符もテスト用の手帳に保存します。サンプルの切符には `SAMPLE` の印があります。

Vercelの `hosi121s-projects/syasou` にデプロイしています。更新はプロジェクトのルートで `npx vercel deploy --prod --scope hosi121s-projects` を実行します。ビルド設定は `vercel.json`、アップロード対象外のファイルは `.vercelignore` に記載しています。

## 起動

Node.js 22.12以降。

```sh
npm install
npm run dev
```

http://localhost:5173 を開きます。`npm run build` で型チェックと本番ビルド、`npm run preview` で本番ビルドの確認ができます。`dist/` は静的配信可能です。

## MoonBit のロジックを変更する

画面は React / TypeScript、旅の状態遷移と切符の発行・編集は MoonBit です。`moonbit/domain/` は JavaScript に依存しない型付きコア、`moonbit/bridge/` は `mizchi/js_core@0.13.0`（`mizchi/js` から分離された基礎バインディング）による変換層です。React、ブラウザ保存の検証、WebGL、音の処理は TypeScript に残しています。

MoonBit を JavaScript の ES Modules にコンパイルし、`src/generated/moonbit/` に生成コードとコンパイラの型定義をコミットします。通常の起動・Vercel ビルドには MoonBit のインストールは不要です。`npm run build` はソースと生成物のハッシュを照合し、再生成を忘れていた場合は失敗します。CI は固定バージョンで再コンパイルして生成物の一致も確認します。

ロジックの変更には Node.js 24.13.0 と MoonBit `0.10.13+cbb11c36f` を使用します。[公式インストーラ](https://www.moonbitlang.com/download/)でバージョンを指定してインストールできます。

```sh
curl -fsSL https://cli.moonbitlang.com/install/unix.sh -o /tmp/install-moonbit.sh
bash /tmp/install-moonbit.sh '0.10.13+cbb11c36f'
export PATH="$HOME/.moon/bin:$PATH"
moon update
npm run test:moonbit
npm run build:domain
npm run check:domain
npm run test:domain
npm run build
npm test
npm run test:mobile
```

別の場所にインストールした場合は `MOON_BIN=/path/to/moon` を指定できます。`moon fmt` と `moon info` の後は `npm run build:domain` を実行してください。生成した JavaScript・型定義は手で変更しません。Vercel の `npm run build` → `dist/` という配信構成はそのまま使います。

移行前の実装・API型定義・実装から生成した期待値は `tests/contract/` に保存しています。`npm run check:domain` は生成物の再現性、期待値の更新漏れ、公開 API の型の一致を検証します。`npm run test:domain` は値・入力の非変更・オブジェクト参照の維持を比較します。`npm run fixtures:domain` は凍結した TypeScript から期待値と MoonBit の直接テストを生成します。互換性の詳細とロールバック先は [移行契約](tests/contract/README.md) を参照してください。

## 操作

- タイトル画面の「窓辺へ」から入ります。既存の列車マークと「車窓」のロゴを使い、読み込み中も同じ紙と窓の画面を表示します。同じタブの再読み込みではタイトルの操作を省略します。
- 初回は小さな「旅のしおり」で手帳・車窓・切符を案内します。途中で実際の車窓モードを見せ、最後の「切符を受け取る」で「はじめての窓辺」の記念切符が箱へ届きます。裏面を読んだり書き込んだりして、「手帳にしまう」で実際の手帳が開き、右ポケットにフォーカスが移ります。待ち時間はなく、タイマーも自動で始まりません。途中でスキップやEscapeも使えます。
- 記念切符には `WELCOME` の印があります。作業完了の切符とは別に保存し、案内を繰り返しても同じ一枚を見せます。書き直した内容や日付は保持します。受け取ったまま再読み込みしても、手帳にしまうところから続けられます。
- しおりを読み終えるかスキップすると、そのブラウザでは自動表示しません。進行中の旅や切符がある既存ユーザーにも自動表示しません。タイトルの「使い方を見る」と右下の本アイコンからいつでも読み直せます。
- 閉じた手帳をクリックして開く。紙の再生ボタンで乗車すると手帳が閉じ、列車の音が始まります。
- 手帳の時刻をクリック、または左下の調整アイコンで設定を開く。作業・休憩時間、速度、光、音量、時計の表示を変更できます。
- 紙に印刷された列車種別をクリックすると、各駅・準急・特急が切り替わります。
- 手帳の空白にはメモを書けます。左下のスピーカーで消音、乗車中の四角いボタンで終了。
- 作業時間が終わると、切符が紙の箱へ置かれるカットインが出ます。「旅を終える」で手動終了した場合も発行します。休憩終了時には追加発行しません。
- 切符の表には手帳メモの一行目、日付、出発時の列車種別・景色が残ります。作業名はその場で書き直せます。回転アイコンで裏返すと、その旅のメモを読んだり追記したりできます。
- 切符の端や帯を押したまま動かすと、紙が浮いて指先についてきます。左右に引いてめくり、十分にめくってから離すと裏返ります。浅くめくって離すと元へ戻ります。つまんでいる間のEscapeは操作を取り消します。文字欄はそのまま入力・選択でき、キーボードでは回転ボタンで表裏を切り替えられます。
- 「手帳にしまう」で窓辺へ戻ります。手帳の右ページにある切符のポケットから、保存した切符を一枚ずつ見返せます。
- 窓をクリックすると窓の外に視点が移ります。もう一度クリック、またはEscapeで座席へ戻ります。
- 右下の「眺めを選ぶ」から、山あいの窓・雪原の窓・遠くの列車を選べます。雪原は提供された空と雪の素材を重ね、近い雪ほど速く流します。外観では小さな列車と広い雪原を眺められます。作業を続けたまま切り替えられ、選んだ眺めは再読み込み後も残ります。
- 外観の手帳アイコンで窓辺の手帳を開けます。戻る矢印やEscapeでも窓辺へ戻れます。眺めの選択メニューを開いている場合、Escapeはメニューだけを閉じます。
- 窓脇の金具で窓を開閉すると、風と走行音の聞こえ方が変わります。
- ポインターを動かすと右下にタイトル・しおり・全画面のボタンが現れます。操作がない間は消えます。キーボードフォーカス中は表示されます。タイトルへ戻っても作業や切符はリセットされません。

作業終了時は車窓が止まって休憩へ移ります。次の出発は自分のタイミングで。手帳を閉じている間はタイマーや通知文を画面に表示しません。ブラウザのタイトルと手帳で状態を確認できます。

設定・メモ・進行中の作業・切符はlocalStorageに保存され、再読み込み後も残り時間を時刻から復元します。離れている間に到着した場合は、次に開いたときに切符を発行します。切符は一つの旅につき一枚で、再読み込みや休憩終了で重複しません。保存先は同じブラウザ内で、端末間の同期はありません。音は再読み込み後に手帳から再生してください。

スマートフォンでは、縦画面の手帳を1ページの紙面で表示します。設定と切符のポケットは紙面内から操作でき、小さな画面やキーボード表示時は紙面の中をスクロールできます。切符の箱は縦長、切符は横向きのまま。端から左右に指を動かしてめくり、文字欄では通常の入力・縦スクロールができます。横向きにしても進行中の作業は引き継ぎます。

タッチ端末では右下の小さな操作ボタンを常時表示します。全画面ボタンはブラウザが対応する場合に表示します。駅ホーム、フレンド機能は今回の実装に含みません。

## ホーム画面から使う

iPhoneではSafariの共有メニュー、Androidでは対応ブラウザのメニューから「ホーム画面に追加」または「アプリをインストール」を選べます。追加後は「車窓」のアイコンから独立した画面で起動します。縦横どちらの向きでも使えます。`public/manifest.webmanifest` とApple向けのメタ情報に起動設定をまとめています。

起動・再読み込みには通信が必要です。タイマーや手帳の記録は端末のブラウザ内に保存します。通常のブラウザとホーム画面のアプリで保存領域が異なる場合があり、端末間の同期は行いません。アイコンは既存の列車マークから生成し、`npm run icons` で再生成できます（PlaywrightのChromiumが必要です）。

## 表現と構成

- `index.html` / `public/opening.css`: JavaScriptが届く前のロゴとローディング画面。読み込みエラー時には再試行を案内します。
- `src/Startup.tsx` / `src/components/Opening.tsx`: 実際のアプリ・紙・フォントの準備に連動した読み込みとタイトルから窓辺へのフェード。装飾素材の失敗で入場が止まらないようにし、アプリ本体の失敗時には再試行できます。タイトルの確認はsessionStorageに保存します。
- `src/components/Onboarding.tsx`: 3段階の旅のしおり。Radix Dialogでフォーカスを管理し、最後は記念切符のカットインから手帳へ、スキップ時は窓辺へ戻します。切符をしまうかスキップすると、確認済み状態を `syasou.onboarding.v1` に保存します。
- `src/lib/profile.ts` / `sampleTickets.ts`: `?demo=1` のテスト用保存領域と初期切符。通常のキーには触れず、localStorage / sessionStorageの各キー末尾に `.demo` を付けます。
- `src/lib/windowRenderer.ts`: 霧に重なる山並み、谷、針葉樹をWebGLで描画。遠景はゆっくり、近くの木々は速く右から左へ流れ、列車種別で速度が変わります。連続した座標から風景を生成するため、素材の継ぎ目はありません。明暗を白黒の粒子に変換し、粒子自体は固定。24fps上限。タブ非表示・停止中・動きを減らす設定では描画ループを停止します。WebGLを利用できない場合もSVGの山と木々が流れます。
- `src/components/Landscape.tsx`: 車窓の表示。後から届く景色素材はこの層に組み込めます。
- `src/components/SnowScenery.tsx` / `src/scenery.css`: 提供された空・雪原・列車をCSSで合成。鏡像を交互につないだ3層が異なる速さで流れます。停止中、切符の表示中、タイトルの裏、タブ非表示時は動きを止め、OSの「動きを減らす」設定にも従います。素材の読み込みに失敗すると元の風景へ切り替え、再試行できます。
- `src/components/ViewPicker.tsx` / `src/lib/views.ts`: Radixのポップオーバーと選択グループで眺めを切り替えます。眺めは `syasou.view.v1` に保存し、テスト用の手帳とは分離します。画像は `public/scenery/` に元の画質で保存しています。
- `src/components/Notebook.tsx`: 紙・表紙・背表紙をCSSで描く操作可能な手帳。Radix Dialogでフォーカスを管理。
- `src/components/TicketTray.tsx` / `TicketCard.tsx`: 到着のカットイン、切符の箱、編集できる切符の表裏。Motionで紙の移動と反転を描き、動きを減らす設定では即座に表示します。
- `src/components/TouchableTicket.tsx`: ポインターキャプチャとMotionのばねで、つまむ・持ち上げる・傾ける・めくる動作を制御。紙の厚み、ミシン目、透かし、光と影をCSS 3Dで描画します。キャンセル・フォーカス喪失では元の面に戻り、動きを減らす設定では傾きを省いて表裏だけを切り替えます。
- `moonbit/domain/tickets.mbt` / `src/lib/tickets.ts`: 切符の発行・編集を MoonBit で処理し、TypeScript の既存 API と保存データの検証を維持します。旅・切符・カットイン確認済み状態を `syasou.travel.v2` にまとめて保存し、旧バージョンの進行中データを移行します。
- `public/ticket-tray.png`: ユーザー提供の空の紙箱画像をそのまま使用。
- `src/components/Settings.tsx`: 手帳の設定ページ。
- `src/App.tsx`: 窓辺と物体の配置、Motionによる視点移動。大きな動きはOSの設定に従って停止。
- `moonbit/domain/journey.mbt` / `src/lib/journey.ts`: 作業・休憩・停止の状態管理と、React から呼ぶ既存の型付き API。
- `src/lib/sound.ts`: Web Audio APIで合成する列車・雨・風の音。音源配信やAPIキーは不要。
- `scripts/create-grain.mjs`: 紙の粒子をコードで生成。`node scripts/create-grain.mjs` で再生成できます。

## 検証

```sh
npx playwright install chromium
npm test
```

スマートフォンのレイアウトとタッチ操作は `npx playwright install --with-deps chromium webkit` の後に `npm run test:mobile` で検証します。Android相当のChromiumとiPhone相当のWebKitで、初回案内・切符・320px幅・横向き・キーボード相当の表示領域変更を確認します。ChromiumではCDPから実際のタッチ入力を送り、指での反転とキャンセルも検証します。実機のキーボードやホーム画面追加は端末上でも確認してください。

既存のChromiumを使う場合は `CHROMIUM_PATH=/path/to/chromium npm test`。初回案内、スキップと再表示、読み込み・再試行、既存データの維持、時間の復元、操作、視点切替、音、PCの表示範囲、粒子の無彩色性、動きを減らす設定、WebGL未対応時、アクセシビリティに加え、切符の発行・編集・閲覧・再読み込み時の重複防止・旧データの移行・保存失敗時の表示を確認します。

## フォント

Shippori MinchoとDM Monoをローカル配信します。Shippori MinchoはUIの文字をサブセット化済み。タイトルの「車窓」は2文字の専用サブセットをHTMLから先読みします。入力したメモで含まれない文字はOSのフォントへフォールバックします。ライセンスは `public/fonts/Shippori-Mincho-LICENSE.txt` と各フォントパッケージ内にあります。

日本語UIの変更後、必要に応じてPythonの `fonttools[woff]` を用意して `npm run fonts` で再生成できます。通常の起動とビルドにPythonは不要です。
